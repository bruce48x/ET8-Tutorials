## 阅读方法

每篇教程都按同一种结构展开：

```text
这篇解决什么问题
先建立通用概念
再解释 ET8 中的关键对象和调用链
然后用本仓库路径举例
最后给新人排查清单
```

不要一开始就记所有类名。先抓住几条主线：

```text
客户端入口 -> 网络连接 -> 协议消息 -> 服务端 Scene/Fiber -> 业务处理 -> 返回或推送
```

理解这条线后，再去看 UI、热更、部署和深入原理。
