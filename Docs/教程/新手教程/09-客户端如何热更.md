# 客户端如何热更

这篇解释客户端热更的日常开发流程。

结论先说：客户端热更主要依赖 HybridCLR 和 ET 的程序集拆分。你修改 `Hotfix`、`HotfixView` 等代码后，执行 `ET/Compile` 生成 `.dll.bytes`，运行时由 `CodeLoader` 加载。

## 哪些程序集参与客户端热更

本仓库客户端关注四个程序集：

```text
Unity.Model
Unity.ModelView
Unity.Hotfix
Unity.HotfixView
```

`AssemblyTool.DllNames` 里也列出了它们：

```text
Unity/Assets/Scripts/Editor/Assembly/AssemblyTool.cs
```

它们会被编译成 dll，再复制成：

```text
Unity/Assets/Bundles/Code/Unity.Model.dll.bytes
Unity/Assets/Bundles/Code/Unity.ModelView.dll.bytes
Unity/Assets/Bundles/Code/Unity.Hotfix.dll.bytes
Unity/Assets/Bundles/Code/Unity.HotfixView.dll.bytes
```

## 日常开发流程

修改客户端热更代码后：

```text
保存源码
Unity 菜单 ET/Compile 或 F6
确认 Assets/Bundles/Code/*.dll.bytes 更新时间变化
运行或重新加载
```

在 Editor 播放中，可以用：

```text
ET/Reload 或 F7
```

它会调用：

```text
CodeLoader.Instance.Reload()
```

## CodeLoader 做什么

客户端加载代码的位置：

```text
Unity/Assets/Scripts/Loader/CodeLoader.cs
```

它会根据运行环境选择加载方式：

```text
非 Editor：从资源系统加载 Assets/Bundles/Code/*.dll.bytes
Editor 且 EnableDll：从 Define.CodeDir 读取 dll.bytes
Editor 且非 EnableDll：从 AppDomain 当前程序集里找 Unity.Model、Unity.Hotfix 等
```

加载完成后，`CodeLoader` 会创建 `CodeTypes`，再反射调用：

```text
ET.Entry.Start
```

## HybridCLR 做什么

打 IL2CPP 包时，C# 代码不再像 Mono 那样直接动态解释执行。HybridCLR 让客户端可以加载热更新程序集，并为 AOT 泛型等场景补充元数据。

本仓库里 AOT 元数据相关目录：

```text
Unity/Assets/Bundles/AotDlls/
```

编辑器工具：

```text
Unity/Assets/Scripts/Editor/Plugins/HybridCLR/HybridCLREditor.cs
```

常见流程来自 ET 运行指南：

```text
HybridCLR Installer
HybridCLR Generate All
HybridCLR CopyAotDlls
ET/Compile
```

## 什么改动不能只靠热更

不是所有改动都适合只更新热更 dll。

通常需要重新打包或更谨慎处理的情况：

```text
修改 Loader、Core、ThirdParty 等非热更程序集
修改 Unity 原生插件
修改资源打包流程
修改 AOT 泛型依赖并需要补充元数据
修改启动链路本身
```

`Hotfix` 和 `HotfixView` 的行为修改最适合热更；稳定定义和底层启动逻辑要谨慎。

## 资源热更和代码热更不同

客户端热更通常包括两类：

```text
代码热更：dll.bytes
资源热更：Prefab、图片、配置、AssetBundle
```

`CodeLoader` 只解释代码加载链路。资源加载还涉及 YooAsset、Bundles 和资源版本管理，不能和 C# dll 热更混为一谈。

## 新人排查清单

1. 改了代码没生效，先执行 `ET/Compile`。
2. Editor 里没加载新 dll，检查 `GlobalConfig.EnableDll`。
3. F7 Reload 无效，确认正在 Play 模式。
4. IL2CPP 包里出泛型或元数据问题，检查 AOT dll 是否复制。
5. 修改 Loader 或 Core 后，不要指望只替换 Hotfix dll。
6. 代码热更和资源热更分别排查。
